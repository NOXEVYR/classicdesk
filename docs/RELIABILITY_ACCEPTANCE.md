# 启动与文件窗口可靠性验收

2026-10-25 的私有 v17 已完成以下实际验证。0.11.21-preview 沿用其修复实现，发布版本仅更新程序集版本标识；发布资产另作构建、包校验和隔离运行核对。

## 本机开机与持续自启

在 Windows 11 26H2 26300.9711 上完成真实整机启动。日志记录增强自动加载，用户确认任务栏保存样式、开始菜单、图标点击，以及新文件窗口的 Win10 导航栏、标题拖动、主页/共享/查看和地址栏均正常。完成脚本写入与实际组件、系统及方案匹配的兼容记录，服务保持运行并设为 Automatic；后续读回仍为 Running/Auto。

准备许可不再因超过六小时而自动失效。一次诊断与持续自启接受记录分开；当前会话恢复不能代替开机验收。未知系统/组件组合仍须重新核对，不能复用另一台机器的接受记录。

## 原版设置面板的真实旧窗口重建

为避免扰动工作桌面，另外建立可回退的独立 Windows 11 26H2 26300.9457 虚拟机。它未挂载宿主磁盘或共享用户目录，所有窗口均为专用合成目录。虚拟机与实际电脑的 OS 修订号不同；两者 explorerframe.dll 均为 10.0.26100.8972，但不能据此宣称所有系统文件相同。

使用原候选程序集，从“桌面设置 → 资源管理器 → 打开并检查新窗口 → 重建旧窗口”进入；没有替换生产协调器、绕过身份/目录/标签检查或从测试代码调用内部关闭方法。

- 启用前保留两个真实 Modern 窗口；只选择其中一个单标签本地目录。
- 生产面板读取窗口、选择并确认后，单次请求创建同目录替代窗口；确认 Ribbon 结构后关闭所选旧窗口。
- 原窗口消失，新 HWND 的目录一致；未选中对照窗口的 HWND、目录及修订完全不变，Explorer PID/创建身份不变。
- 真实鼠标拖动使窗口移动 130×52 像素；主页、共享、查看实际点击后展示各自内容。
- 鼠标点击地址栏进入编辑状态，键盘输入子目录并成功导航。
- 最小化后恢复，关闭后重新打开同目录，均保持完整 Ribbon、地址/导航/搜索行。
- 选择有效合成 MP4，点击“视频工具”，折叠及展开功能区后，导航行仍可见。这覆盖了原故障截图中的上下文页场景。

实际过程观察到一次启用前修订拒绝：首次登录时 Explorer Advanced 键时间戳变化，对齐值未变。原窗口保留；重新检查后启用成功。测试驱动将该拒绝作为未捕获异常退出并记录应用错误；没有据此把 Explorer 算作崩溃。后续未观察到 Explorer、ClassicDesk 或开始菜单宿主崩溃。一次 UIA 枚举失败不计通过，地址栏操作由实际截图和后续目录/结构读回确认。

## 修复内容

- Ribbon 创建路径与现代顶栏钩子分离；导航初始化后恢复正确重绘，检查失败不冒报初始化成功。
- 模块热加载不强改已存在的现代对象；显式重建只处理身份、目录和单标签可核对的目标。
- 临时 COM/UIA 读取失败在原截止时间内重新观察；打开、关闭最多各一次，不因未知结果重复执行。多标签、选择中、模态、外部变化或信息不足时保留旧窗口。
- 服务启动、一次开机诊断、当前会话恢复和持续自启完成分别记录，修正运行时长判断及过期许可导致的未加载。
