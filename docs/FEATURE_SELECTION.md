# 按需启用功能（本地 0.11.2-dev）

在“系统应用检查”中可分别勾选任务栏布局、图标与尺寸、资源管理器、右键菜单。首次打开仍只勾选方案允许的任务栏选项；其他两项需单独选择。四项共用一个增强引擎，不为每项启动一个后台程序。

| 选择 | 应用内容 |
| --- | --- |
| 任务栏布局 | 应用居中，并按方案决定开始按钮是否独立靠左；未勾选则保留原任务栏对齐值，包括原值不存在的情况 |
| 图标与尺寸 | 图标大小、栏高、按钮宽度及小图标模式尺寸；不勾选时尺寸模块停用 |
| 资源管理器 | 按方案选择 Windows 10 功能区或经典导航栏；前者不保留 Windows 11 标签页 |
| 右键菜单 | 完整菜单及可选的 Ctrl 临时切回新版；命令内容仍由文件类型和已安装扩展决定 |

资源管理器、右键菜单若在方案中选了 Windows 11 原生样式，对应增强选框不可选。需要先回到设置页选择功能区、经典导航栏或完整菜单。所有增强都未选择时不启动引擎；仅选择原生居中布局也不单独启动引擎。

任务栏页的“高级布局”中有“启用布局调整”和“启用尺寸调整”两个方案开关，可以随方案保存、导入导出和载入；关闭不删除原来的尺寸或位置参数。预览继续展示设计，并标记部分增强未选择。检查面板中的临时勾选仅决定这一次应用范围，不覆盖保存的方案。

更改勾选后，旧检查结果和试用按钮立即失效。点击“重新检查”后才可试用。已有方案正在运行时，需先恢复上次组合，再检查新的组合。恢复记录保留全部配置原始字节及对齐值，只恢复确认由本次事务修改且未被外部改动的项。

本地单屏已观察到开始靠左、应用居中分离和 Win10 功能区；右键菜单的实际行为、其他显示条件、系统更新兼容性仍需验证。资源管理器样式需在新开的窗口检查，旧窗口不一定立即切换。

增强运行时可以启用[登录恢复](LOCAL_RUNTIME.md#登录后继续已有增强)；引擎退出而配置仍有效时可以点“继续运行”。登录恢复只接续原事务，不把草稿当作已应用方案。空闲采样和当前限制见[性能记录](PERFORMANCE.md)。
