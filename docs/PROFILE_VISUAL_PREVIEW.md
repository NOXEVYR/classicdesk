# 随设置变化的桌面效果图 · 0.11.20-preview

目标是让用户设置后立即看见对应的大致布局。设置页保留预览，方案页提供大图和每套方案的缩略图；二者均从当前完整 ShellProfile 绘制，无需应用系统设置。

![当前方案大图](screenshots/profile-library.png)

![已保存方案卡片](screenshots/profile-cards.png)

| 设置 | 图中展示 | 适合查看的场景 |
| --- | --- | --- |
| 开始靠左、全部居中、全靠左 | 开始按钮、系统按钮和应用组的位置 | 普通桌面 |
| 图标大小、按钮宽度、任务栏高度 | 图标尺寸、按钮间距和栏高 | 普通桌面 |
| 小图标与小按钮宽度 | 小图标状态的尺寸和间距 | 小图标 |
| 其他系统按钮靠左 | 搜索、任务视图与应用组分开 | 普通桌面 |
| 开始菜单位置 | 开始弹层在左侧或居中 | 开始菜单 |
| 搜索菜单位置 | 从任务栏搜索入口进入时的弹层位置 | 搜索入口 |
| 紧凑系统托盘 | 右侧状态图标之间的间距 | 普通桌面 |
| 透明任务栏 | 桌面背景从任务栏透出 | 普通桌面 |
| 最大化或全屏时不透明 | 最大化时的任务栏背景变化 | 窗口最大化 |
| 三种资源管理器工具区 | 功能区、导航和命令栏布局；标签页按所选模式展示 | 普通桌面或资源管理器页 |
| 完整右键菜单 | 完整菜单与现代菜单的结构 | 右键菜单 |
| Ctrl 临时切换 | 按住 Ctrl 时展示现代菜单或保持完整菜单 | Ctrl 菜单 |
| 布局增强、尺寸增强 | 启用标识；未启用时以系统参考位置/尺寸表示 | 各场景 |
| 布局方案与界面皮肤 | 方案名称、图示配色及当前组合 | 各场景 |

通过预览上方的菜单切换场景。普通模式不套用小图标参数；窗口最大化才会显示最大化条件下的不透明效果。开始/搜索位置遵循有效的布局依赖，全靠左时使用原生位置参考。Ctrl 切换仅在完整菜单已启用时生效。关闭布局增强后，透明、最大化跟随与紧凑托盘参数保留在草稿中，但图示按默认启用面板的有效选择绘制；重新开启后恢复对应效果。

编辑设置时自动展示关联场景：小图标参数进入小图标，开始/搜索位置展开对应弹层，最大化跟随进入最大化，Ctrl 参数进入 Ctrl 菜单。普通尺寸、任务栏布局、透明/托盘和资源管理器编辑回到普通桌面。预设、皮肤、导入、库载入与撤销保留所选场景；状态菜单仍可以手动切换。

悬停预览区域可以查看当前场景和依赖条件的解释。画面上的尺寸是示意参数，整体按可用空间缩放；大图、缩略图、小窗预览使用同一绘制组件。小窗口精简文件内容，保留工具区、任务栏与弹层。保存方案后，卡片使用已保存参数绘制，继续编辑不会悄悄改变卡片内容。

这是原创合成示意，未读取真实桌面、文件、应用列表、时钟或壁纸。皮肤只是 ClassicDesk 界面配色与图示配色，不负责设置 Windows 壁纸。任务栏在四条边、标签合并和分段设计，以及独立开始菜单的专属选项仍使用已有的布局与开始菜单工作台，未加入 ShellProfile 或真实系统事务。

0.11.20-preview公开保留这些前端预览能力；开发与发布检查没有启用增强、修改任务栏自动隐藏或重启Explorer。离屏渲染不能替代真实多屏/DPI/Windows版本的系统效果验收。
