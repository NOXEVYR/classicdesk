# StartAllBack 功能对照与替代验收清单

基线：StartAllBack 3.9.25；核对日期：2026-09-20。ClassicDesk 对照版本：0.11.2-dev；本轮桌面视觉证据来自 0.11.1-dev（源提交 `325c54d`），0.11.2 增加登录恢复及状态说明。目的：在原插件移除前记录功能，后续逐项补齐，避免把少数任务栏选项完成误写成完整替代。

## 状态和使用规则

- **待实机**：ClassicDesk 已有参数、模块配置和隔离验证，但未验证真实桌面效果；不能标为替代完成。
- **部分／待实机**：只覆盖部分行为，或实现方式与原插件不同。
- **未实现**：当前方案模型、运行模块与界面没有对应能力。
- **前端已验**：仅指 ClassicDesk 自身编辑、保存或皮肤能力，不能算 Windows 外观已改变。
- **待核实**：来自官方说明，或受系统版本/开关条件影响，尚无本机交互证据。

来源代号：`S` 为本机开始菜单页；`T` 为任务栏页及展开的选项；`Y` 为托盘页；`E` 为资源管理器页；`A` 为高级页；`W` 为欢迎页；`O` 为[官方功能及版本记录](https://www.startallback.com/)；`C` 为 ClassicDesk 源码与本地验证。界面截图、完整控件树、当前个人设置及备份只保存在本地，不提交公共仓库。

ID 保持稳定。实现一项后应更新对应行并关联代码、隔离检查、实机前后效果与恢复证据。未测、缺组件、冲突阻断、只画了预览均不能勾选完成。原插件六个功能设置页均已读取，“关于”中的授权信息不采集；没有为了调查而执行清空记录、切换电源动作或修改系统隐私开关。已保存各页控件文字与部分截图，截图未覆盖所有页面。条件功能及未展开枚举明确留待核实，不宣称已经穷尽所有隐藏行为。
