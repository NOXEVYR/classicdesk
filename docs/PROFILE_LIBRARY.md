# 本地方案库（0.11 开发版）

打开侧栏“方案管理”，顶部为本地方案库。四套内置布局与六款皮肤继续保留，方案库用于保存自己调好的完整组合。

| 操作 | 结果 |
| --- | --- |
| 新增当前草稿 | 输入不同名称，将当前所有参数与皮肤存为独立条目；不改当前保存方案或 Windows |
| 载入预览 | 将所选条目载入编辑草稿，切换到任务栏、资源管理器或菜单页查看效果 |
| 撤销载入 | 回到载入前的草稿，包括原本未保存的修改；载入后又编辑过时不直接覆盖新编辑 |
| 更新为当前草稿 | 用当前草稿替换选中条目的参数；想保留两个版本时先复制 |
| 复制 | 保留原条目，生成独立副本和不重复的名称 |
| 重命名 | 修改名称，保留身份、参数与归档状态 |
| 归档 / 恢复方案 | 从常用列表移入归档；勾选“查看归档”后可以恢复，条目不会被删除 |
| 刷新 | 重新读取本地文件，处理其他窗口已修改方案库的情况 |

载入后，底部“保存方案”仍用于保存当前编辑方案；方案库和当前方案独立。现有单方案 JSON 导入导出继续可用：导入后可新增到库，载入库中条目后可导出。

方案名称为 1–40 个字符，重名（忽略首尾空格与大小写）会被拒绝。当前支持最多 128 条记录，含归档；文件读取上限 1 MB。名称只是显示文字，不用作文件路径。

方案库位于当前方案文件旁的 `ShellProfile.json.library.json`，默认随 ClassicDesk 本地用户数据保存。仅进入页面或点击操作时读写；不增加文件监视、计时器、后台扫描、网络同步或常驻进程。方案库损坏、版本无法识别或存在外部修订冲突时保留原文件，当前草稿仍可编辑。该文件属于用户配置，不进入 Git 或公开包。

本页管理的是编辑方案。系统启用与恢复仍需独立检查；本次未启用增强引擎，整体系统资源对照尚待实机测试。
